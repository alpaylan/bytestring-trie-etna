# bytestring-trie — ETNA Workload

## Upstream

- Library: [bytestring-trie](https://github.com/wrengr/bytestring-trie) by wren gayle romano
- Synopsis: efficient finite map from `ByteString` to values, based on Okasaki/Morrison big-endian patricia trees.
- Base commit: `56c486dd73beb8c111eea8eb6d0b3f3da3bc1ac0` (HEAD as of clone). The whole upstream package is included verbatim — `bytestring-trie.cabal`, the existing `dev/Test/*` and `dev/Bench/*` directories — they are *not* edited; only the workload-specific `etna/` package, `cabal.project`, `etna.toml`, and `patches/*.patch` are added.

## Layout

```
workloads/Haskell/bytestring-trie/
  bytestring-trie.cabal            # upstream, untouched
  src/                             # upstream sources, patched in/out by `git apply`
  cabal.project                    # ours — packages: . etna/ + with-compiler GHC 9.6.6
  etna.toml                        # ours — manifest with three [[tasks]]
  patches/                         # ours — three buggy→fixed diffs
  etna/

    src/Etna/{Result,Properties,Witnesses}.hs
    src/Etna/Gens/{QuickCheck,Hedgehog,Falsify,SmallCheck}.hs
    app/Main.hs                    # CLI dispatcher: `etna-runner <tool> <property>`
    test/Witnesses.hs              # cabal test-suite: every witness must equal Pass on base

```

## Variants

Three patches, each in `patches/<variant>.patch`. Reverse-applying a patch (`git apply -R --whitespace=nowarn patches/<v>.patch`) installs the bug; forward-applying restores the fix.

1. **`mergeby_arg_order_68ef3934_1`** — `mergeBy` swaps the trie arguments in its right-epsilon `start` arm (`go s1 t0` instead of `go t0 s1`). Detected by left-biased union witnesses where the right trie has an epsilon entry whose subtrie shares keys with the left.
2. **`delete_submap_keeps_children_c7caacad_1`** — `deleteSubmap` returns the old subtree instead of `empty`, leaving every prefixed key intact.
3. **`merge_maybe_drops_left_only_10bfe2dd_1`** — `mergeMaybe`'s `(Just _, Nothing)` case returns `Nothing` instead of preserving the left value, so unions drop entries at any internal-Branch position where the right trie has an Arc-Nothing intermediate node at the same key.

## Backends

`quickcheck`, `hedgehog`, `falsify`, `smallcheck` — driven from `etna-runner`'s `app/Main.hs`. SmallCheck times out (depth 4) on every variant because the bug-trigger inputs require longer keys than the bounded enumeration covers; each `[[tasks.tasks]]` entry is annotated with `smallcheck_timeout = true`.

## How to run

```sh
# Build (also builds upstream library)
cabal build etna-runner

# Replay every witness on the base tree (must succeed)
cabal test etna-witnesses

# Run a single backend × property
cabal run etna-runner -- quickcheck MergeByLeftBiased
cabal run etna-runner -- falsify   DeleteSubmapRemovesAllPrefixed

# Install a bug, retest, restore
git apply -R --whitespace=nowarn patches/mergeby_arg_order_68ef3934_1.patch
cabal run etna-runner -- hedgehog MergeByLeftBiased     # status:failed
git apply    --whitespace=nowarn patches/mergeby_arg_order_68ef3934_1.patch

# Regenerate BUGS.md / TASKS.md from etna.toml
python3 ../../scripts/check_haskell_workload.py . --regen-docs
```

## GHC pin

Pinned to GHC 9.6.6 via `cabal.project`'s `with-compiler:` because Falsify ≥ 0.2 requires `base ≥ 4.18`. The upstream's `tested-with: GHC ==8.0..9.12` field is unaffected — we just don't exercise the older end of that range here.

## Notes on patch synthesis

The pipeline's variant patches are hand-crafted against modern HEAD where the historical `git format-patch -1 <fix-sha>` would not apply cleanly:

- The historical 2010/2011 darcs-imported commits live under the long-gone `Data/` (vs `src/Data/`) layout.
- The historical `intersectBy` of commit `dccbb019` had the signature `(a -> a -> Maybe a) -> Trie a -> Trie a -> Trie a`; modern HEAD generalised this to `(a -> b -> Maybe c) -> Trie a -> Trie b -> Trie c`, so the original arg-swap bug is no longer type-safe to express. Variant 3 therefore re-injects a missing-case-style bug in `mergeMaybe` (the helper introduced in `10bfe2dd`) instead — same family, expressible against modern code.
